# 제품/기획 문서

이 폴더는 **개발자가 아니어도 읽을 수 있게** 쓴 문서를 모은다 — 사업 파트너, 디자이너,
나중에 합류할 비개발자 팀원이 코드를 몰라도 이해할 수 있어야 한다. 전문 용어를 쓸 땐
풀어서 설명하고, 코드 경로/함수명 같은 구현 디테일은 되도록 `docs/engineering/`으로 뺀다.

- [`brand-guide.md`](./brand-guide.md) — 브랜드 아이덴티티(로고, 컬러, 톤)
- [`feature-decisions.md`](./feature-decisions.md) — 지금까지 확정된 제품 기능 결정 사항
- [`business-compliance-checklist.md`](./business-compliance-checklist.md) — 기능이 아닌,
  상업 서비스 운영에 필요한 법률/결제/세무 체크리스트
- [`ops-infra-backlog.md`](./ops-infra-backlog.md) — 운영·인프라·사업 쪽 결정 사항과, 기능 개발
  이후로 미뤄둔 작업 목록(계정 구조, 파일 저장소, 호스팅 등)
- [`launch-roadmap.md`](./launch-roadmap.md) — **사업화 일정**(지금부터 첫 매출까지 단계별 체크리스트)
- [`cost-overview.md`](./cost-overview.md) — 비용 한눈에 보기(기술 비용·운영/사업 비용, 1회·연간)
- [`brand/`](./brand/) — 원본 디자인 가이드·로고 파일·화면 목업 이미지(레퍼런스 자료)
