# 제품/기획 문서

이 폴더는 **개발자가 아니어도 읽을 수 있게** 쓴 문서를 모은다 — 사업 파트너, 디자이너,
나중에 합류할 비개발자 팀원이 코드를 몰라도 이해할 수 있어야 한다. 전문 용어를 쓸 땐
풀어서 설명하고, 코드 경로/함수명 같은 구현 디테일은 되도록 `docs/engineering/`으로 뺀다.

- [`business-compliance-checklist.md`](./business-compliance-checklist.md) — 기능이 아닌,
  상업 서비스 운영에 필요한 법률/결제/세무 체크리스트
- [`brand/`](./brand/) — 원본 디자인 가이드·로고 파일·화면 목업 이미지(레퍼런스 자료)
