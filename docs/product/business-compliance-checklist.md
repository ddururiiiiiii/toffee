# 사업 운영 체크리스트 (기능 아닌 것들)

기능 기획과 별개로, 상업 서비스를 처음 하는 입장에서 놓치기 쉬운 것들을 정리한다.
전문 자문(변호사·세무사)이 필요한 항목은 그렇게 표시했다.

## 1. 인앱결제(IAP) 의무 — 가장 먼저 확인할 것

Apple App Store / Google Play는 앱 안에서 소비되는 디지털 콘텐츠(구독형 DM 접근권 포함)를
**자사 인앱결제로만 팔도록 강제**한다. Stripe 같은 걸로 직접 카드 결제를 받는 구조로
만들면 심사 거절되거나 나중에 강제로 내려갈 수 있다.

- 결제 아키텍처를 짤 때부터 Apple/Google IAP 연동을 전제로 설계할 것.
- 수수료(보통 15~30%)를 사업 계획(구독가 책정)에 미리 반영할 것.
- 나중에 고치기 제일 비싼 영역이라 지금 단계에서 확인 필요.

## 2. 이용약관 / 개인정보처리방침 / 자동갱신 고지 — 변호사 자문 필요

- 앱스토어 심사 자체가 이 두 문서 링크를 요구함.
- 태국 팬 개인정보 → 태국 PDPA, 글로벌 팬까지 고려하면 GDPR 유사 조항도 필요.
- "구독 자동 갱신을 어떻게 취소하는지"를 명확히 고지하지 않으면 여러 나라
  소비자보호법(한국 전자상거래법 포함)에 걸릴 수 있음.
- 사업 로드맵의 법률 자문 단계(7단계)에서 같이 처리하는 걸 권장.

## 3. 태국 배우/소속사에게 대금 지급 시 세무 — 세무사 자문 필요

해외 사업자(소속사)에게 정산금을 보내면 한국에서 **원천징수/해외지급 신고** 의무가
생길 수 있음. 계약(로드맵 7~8단계) 체결 전에 "해외 용역대가 지급 구조"를 세무사에게
한 번 확인받는 게 안전.

## 4. 연령/미성년자 정책

팬덤 서비스는 미성년 팬 비중이 꽤 높음. 실제 인물의 사진/음성/영상을 유료로 주고받는
서비스라 앱스토어 연령 등급 심사와 별개로, 미성년자 결제(부모 동의 등) 문제를 서비스
정책에 미리 정해두는 게 좋음.

## 우선순위

1번(IAP)이 가장 급함 — 결제 구조를 잘못 짜면 되돌리는 비용이 크다. 2~4번은 출시 직전에
처리해도 되지만, 미리 알고 일정에 넣어두는 게 좋다.
