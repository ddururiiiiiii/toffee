# 토피 비용 정리 (기술 비용 · 운영/사업 비용)

2026-09-29 작성. 지금까지 정한 기술·운영 방식 기준으로 **돈이 드는 것만** 모았다. 어떤 기술을 왜 쓰는지는
[`docs/engineering/tech-stack-overview.md`](../engineering/tech-stack-overview.md).

- **규모 가정**: 출시 때 배우 **5~10명**(2026-09-29 사용자 정정 — 예전 문서의 "배우 1명 파일럿"은 틀린 가정).
  서버 비용은 배우 수보다 **팬 수와 영상 양**이 좌우한다.
- 가격은 2026년 기준 어림값(환율 $1 ≈ 1,400원). 실제로 가입할 때 요금표를 다시 확인할 것.
- 예전 추정(2026-09-21, 월 $80~320)보다 **파일 저장 비용을 낮췄다** — 그땐 저장소를 안 정했었고, 지금 정한
  Cloudflare R2는 팬이 받는 전송량이 무료라서.

## 요약

| 시점 | 월 비용(대략) | 내용 |
|---|---|---|
| **지금(개발 중)** | **0원** | 전부 로컬에서 대체품으로 개발. 돈 드는 계정은 아직 없음 |
| **출시 직후**(배우 5~10명, 팬 수백~수천 명) | **기술 약 2만~8만 원 + 사업 약 10만~20만 원** | 서버·DB 호스팅이 대부분. 사업 비용은 법인 설립 후 세무 기장료 |
| **커지면**(팬 1만~3만 명) | **기술 약 20만~55만 원 + 사업 약 15만~30만 원** | 서버·DB 한 단계 올리고, 오류 수집·앱 업데이트 유료 플랜 |
| **1회·연간** | 첫해 약 **20만 원 + 법인 설립 30만~50만 원 + 전문가 검토비** | 스토어 개발자 계정, 도메인, 법인 설립, 변호사·번역 검수 |

매출에서 빠지는 **스토어 수수료(15%~30%)**와 **소속사 정산**은 비용이 아니라 매출 배분이라 아래 따로 적었다.

## D. 매출에서 빠지는 것 (비용 아님, 참고)

- **스토어 수수료**: 구독은 보통 **15%**(애플 소규모 사업자 프로그램 — 연 매출 100만 달러 미만 신청 시, 구글 구독 기본).
  애플에 소규모 사업자 신청을 안 하면 첫해 30%.
- **소속사 정산**: 비율 미정(7:3 / 계약금+6:4 논의만) — `feature-decisions.md` "소속사 계약/정산 조건".
- **세금**: 부가세·해외 매출 세금은 스토어가 일부 대신 처리하는 나라가 많지만, 태국 소속사 지급 세무는 세무사 자문 필요.

## E. 개발 도구 비용

- 코드·라이브러리는 전부 오픈소스라 **0원**.
- iOS 빌드는 Expo 클라우드 빌드로 하면 **맥이 없어도 됨**. 실기기 테스트용 폰(아이폰·안드로이드 각 1대)은 있으면 좋음.
- AI 개발 도구 구독료는 쓰고 있는 플랜 기준이라 이 표엔 넣지 않았다.
