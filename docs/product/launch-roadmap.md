## 지금 위치 (2026-09-29)

- **기능 개발은 1차(첫 출시) 기준 사실상 끝.** 소셜 로그인 버튼, 스토어 결제·복원·결제 알림, 번역, 정산까지 코드는 있고
  (2026-09-29), 남은 건 전부 **계정 가입·키 입력·호스팅·실기기 확인·변호사·계약** 같은 코드가 아닌 일이다.
- 그래서 **지금부터 병목은 개발이 아니라 사업 쪽**이다. 새 기능은 멈추고(새 아이디어는 `STATUS.md` 아이디어 보관함으로),
  시간을 아래 순서대로 쓴다.

## 순서를 정하는 세 가지 전제

1. **실제 아티스트는 소속사 계약 전엔 못 올린다** → 그 전까지는 가상 아티스트 데모로 보여준다.
2. **유료 판매는 법인 설립 후, 법인 명의 스토어 계정으로** → 법인 전엔 내부 테스트만.
3. **예비창업패키지 신청 전엔 사업자 등록 금지**(등록하면 예비창업자 자격이 없어짐) → 법인 설립은 지원사업 결과가 나온 뒤.
   **예외**: 진지한 소속사가 "회사가 있어야 계약한다"고 하면 결과를 기다리지 않고 법인을 먼저 세운다(실제 파트너가 지원금보다 중요).

## 3단계. 소속사 의견 듣기 (11/2 ~ 12/31)

목표는 **서명된 계약서가 아니라 "관심의 증거"**다(사업자 없는 개인에게 MOU를 써 주는 소속사는 드물다).

- [ ] 1차 5곳 연락 → 반응 보고 문구·조건 다듬기 → 2차 5~10곳
- [ ] 콜드 메일보다 **소개**가 잘 통한다: KOTRA 방콕무역관 파트너 발굴 문의, 태국 엔터 쪽 한국 업계 사람, 현지 팬 커뮤니티
- [ ] 받은 답장·미팅 메모는 전부 모아 둔다(4단계 사업계획서 근거) — 예: "N곳 연락, M곳 미팅, 파일럿 검토 의사 K곳"
- [ ] 개발은 **피드백 반영만**. 소속사가 공통으로 원하는 게 있으면 그때 1차/2차에 넣는다
- [ ] 소속사 반응을 보며 정산 비율 초안 정리(`feature-decisions.md` "소속사 계약/정산 조건")

**분기점**
- 반응 있음 + "회사 있어야 한다" → 5단계(법인)를 앞당긴다.
- 3개월 반응 0 → 방향 점검(태국 인디 아티스트·인플루언서부터, 다른 나라 아티스트 등). 지원사업은 그대로 신청.

## 4단계. 지원사업 (2027년 1~3월)

- [ ] 1월: 사업계획서 작성 — 재료는 이미 있음(동작하는 서비스, 젤리 운영 실적, 소속사 반응, 비용 문서)
- [ ] 공고 확인: **K-Startup**(국가 사업 통합), **기업마당**(대전 필터), 대전창조경제혁신센터, 대전정보문화산업진흥원,
  대학 창업지원단(KAIST·충남대·한밭대 — 예비창업패키지 주관기관, 재학생 아니어도 됨), 글로벌·콘텐츠 계열(한국콘텐츠진흥원 등)
- [ ] 신청: 예비창업패키지(청년) + 대전 지역 사업. **재직자 신청 가능 여부**와 **현금 자부담**은 공고마다 다르니 확인
- [ ] 결과 기다리는 동안 견적만 받아 두기: 변호사(약관·정책 표 한 번에), 원어민 번역 검수(태·일·중), 세무사(설립·해외 정산)

> 지원금은 **자본금이 아니다**. 협약한 용도(외주·마케팅·법률 검토 등)에만 쓰고 증빙·정산하는 돈이라 법인 자본금이나
> 생활비로 못 쓴다. 법인 자본금은 개인 돈으로 100만~500만 원 정도 작게 잡는다. 협약 전 지출은 보통 인정 안 되니 영수증은 따로 모은다.

**떨어져도** 법인 설립 후 초기창업패키지(업력 3년 이내)나 지역 사업으로 다시 도전한다.

## 5단계. 법인 설립 (선정 직후 또는 소속사 요구 시)

- [ ] 법인 설립(온라인법인설립시스템 셀프 또는 법무사, 30만~50만 원) → 사업자등록 → **통신판매업 신고** → 법인 계좌
- [ ] **D-U-N-S 번호 바로 신청**(무료, 발급에 몇 주 걸림 — 애플·구글 법인 계정의 선행 조건이라 가장 먼저)
- [ ] 세무사 기장 계약(월 10만~20만 원). 첫 상담에서 물을 것: 청년창업 세액감면(대전은 대상 지역), 무보수 대표이사,
  태국 소속사 지급 원천징수, 코드·자산(토피·젤리)을 개인 → 법인으로 넘기는 방법, 젤리 수익을 법인 매출로 잡는 시점
- [ ] **젤리도 법인 사업으로**(2026-09-29 결정 — 젤리용 개인사업자는 따로 내지 않음). 젤리 중고거래는 이때부터 준비 가능
  (법인 명의 통신판매중개업 신고)
- [ ] 애플: **지금 개인 개발자 계정을 법인으로 전환**(젤리 그대로, 판매자 이름만 법인명) → 전환 끝난 뒤 토피 운영 번들 ID 등록
- [ ] 구글: **법인 명의 조직 계정 새로** 만들어 토피 등록 + 젤리는 앱 이전 기능으로 옮기기
- [ ] 이미 만든 서비스 계정(Cloudflare·Firebase·Sentry·Expo·소셜 로그인)은 **새로 만들지 말고 소유자·회사 정보만 변경**
  (새로 만들면 기존 로그인 회원 식별값이 달라짐)
- [ ] 직장: 겸업금지 조항 다시 확인. 법인에서 급여를 받지 않는 **무보수 대표**면 4대보험으로 드러날 일은 거의 없음(세무사 확인)

## 7단계. 출시·파일럿 (3개월, 목표 2027년 여름)

- 아티스트 5~10명, 태국 팬 중심.
- 돈의 흐름: 팬 결제 → 스토어가 수수료 떼고 **약 1~2개월 뒤** 법인 계좌로 → 소속사 정산·해외 송금. 첫 달 매출은 늦게 들어온다.
- 매주 볼 숫자: 구독 전환율, **월 해지율(가장 중요)**, 아티스트 발송 빈도, 환불·신고 건수, 문의 건수.
- 이 숫자가 다음 소속사를 설득하는 영업 자료가 된다.

## 8단계. 확장 · 채용 · 퇴사 판단

- 같은 소속사의 다른 아티스트 → 다른 소속사로. 젤리(같은 법인 서비스)는 GL 팬 유입 창구로 활용, 젤리 중고거래도 이 무렵.
- 2차 기능(번역 LLM, 정산, PC 웹 화면)은 이 단계 전후로 — 정산은 소속사가 3곳을 넘기 전에.
- 채용·퇴사 기준은 [`business-faq.md`](./business-faq.md) 7번·8번.
