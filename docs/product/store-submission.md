# 스토어 제출 자료 (앱스토어·플레이스토어)

2026-09-29 작성. 스토어에 앱을 등록할 때 콘솔에 **그대로 옮겨 적으면 되는** 내용을 모아 둔 문서. 실제 코드가
모으는 정보 기준이라, 수집 항목이 바뀌면(새 기능) 이 문서도 같이 고칠 것.

- 앱스토어: App Store Connect → 앱 → "앱 개인정보 보호"
- 플레이스토어: Play Console → 앱 콘텐츠 → "데이터 보안"
- 둘 다 **개인정보처리방침 주소**가 필요 → `https://<API 주소>/legal/privacy` (서버에 이미 있음, 초안)
- **지원(고객센터) 주소** → `https://<API 주소>/support` (서버 `SUPPORT_EMAIL`에 회사 메일을 넣으면 표시)
- 이용약관 주소(애플 "사용권 계약(EULA)" 칸에 넣을 수 있음) → `https://<API 주소>/legal/terms`

## 1. 모으는 정보 (앱 개인정보 보호 / 데이터 보안)

| 정보 | 애플 분류 | 구글 분류 | 왜 모으나 | 사람과 연결됨 | 추적(광고)에 씀 |
|---|---|---|---|---|---|
| 이름·이메일(소셜 로그인에서 받음) | 연락처 정보 — 이름, 이메일 주소 | 개인 정보 — 이름, 이메일 주소 | 계정 만들기·로그인 | 예 | 아니요 |
| 닉네임 | 사용자 콘텐츠 — 기타 | 개인 정보 — 기타 | 앱 기능(채팅방에 표시) | 예 | 아니요 |
| 생년월일 | 기타 데이터 | 개인 정보 — 기타 | 이용 연령 확인(성인만) | 예 | 아니요 |
| 국가(기기 지역 설정) | 대략적 위치 아님 → 기타 데이터 | 개인 정보 — 기타 | 연령 기준·통계 | 예 | 아니요 |
| 팬이 보낸 메시지(답장) | 사용자 콘텐츠 — 기타 사용자 콘텐츠 | 메시지 — 기타 인앱 메시지 | 앱 기능 | 예 | 아니요 |
| 구독·구매 기록 | 구입 항목 — 구입 내역 | 금융 정보 — 구매 내역 | 앱 기능(구독 확인) | 예 | 아니요 |
| 푸시 알림용 기기 토큰 | 식별자 — 기기 ID | 기기 또는 기타 ID | 알림 보내기 | 예 | 아니요 |
| 마지막 접속 시각·사용 기기 종류 | 사용 데이터 — 제품 상호작용 | 앱 활동 — 기타 작업 | 통계(운영자 대시보드) | 예 | 아니요 |
| 앱 오류 기록(Sentry) | 진단 — 충돌 데이터, 기타 진단 | 앱 정보 및 성능 — 비정상 종료 로그, 진단 | 오류 고치기 | 아니요(회원 정보 안 보냄) | 아니요 |

- **모으지 않는 것**: 정확한 위치, 연락처(주소록), 사진첩 내용(팬은 사진을 못 보냄 — 아티스트가 보낼 사진만 그 순간 고름),
  결제 카드 정보(애플·구글이 처리), 광고 ID.
- **광고·추적 없음** → 애플 "추적 허용" 팝업(ATT) 필요 없음.
- 데이터는 **전송 중 암호화**(HTTPS), 이용자가 **삭제 요청 가능**(앱 안 회원 탈퇴) — 구글 데이터 보안 질문에 "예".

## 2. 연령 등급

- 애플: 연령 등급 질문에서 "사용자 생성 콘텐츠(팬 답장)" 있음 → **17+ 또는 18+** 선택(2026-09-29 결정: 성인만 가입과 맞춰
  가장 높은 등급). 구글: IARC 설문 → "사용자 간 소통 있음", 대상 연령 **18세 이상**.
- 사용자 생성 콘텐츠가 있는 앱의 애플 요구사항(가이드라인 1.2)은 이미 갖춤: 신고(아티스트 메시지·팬 답장), 차단(아티스트·소속사가 팬
  차단), 금칙어 자동 차단, 운영자 처리, 약관에 금지 행위 명시.

## 3. 심사용 계정(심사 담당자에게 줄 것)

- 운영 서버는 테스트 로그인(`ENABLE_DEV_LOGIN`)이 꺼져 있어서, 심사 담당자가 **실제 소셜 로그인으로 들어와 구독까지 해 볼 수
  있어야** 함 → 심사용 구글(또는 애플) 계정 하나를 만들어 성인 생년월일로 가입해 두고, 스토어 **샌드박스 결제**로 구독 가능한지 확인.
- 심사 메모에 적을 것: 팬은 사진·음성·영상을 보낼 수 없음(아티스트만), 아티스트 계정은 운영자가 만들어 줌(심사용 아티스트 계정이 필요하면 따로),
  구독은 아티스트별·묶음 두 종류.

## 4. 스크린샷(나중에 실기기로)

필요한 화면: 둘러보기, 아티스트 프로필(멤버십), 채팅방(사진·음성), 사진 크게 보기, 구독 확인, 묶음 구독. 크기는 애플 6.9인치
(1320×2868)·6.5인치, 구글 휴대폰. 실기기 빌드 후 실제 아티스트 사진으로 찍는 게 좋음(지금 웹 화면은 데모 데이터).
