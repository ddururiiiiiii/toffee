# 번역 AI 비교 예문 세트 (GPT vs Claude)

2026-10-02. 메시지 번역에 쓸 AI를 고르기 위한 무료 비교. chatgpt.com과 claude.ai(무료 계정)에 **아래 두 묶음을 똑같이** 붙여넣고
결과를 비교한다. 지시문은 토피 서버가 실제로 쓰는 번역 지시를 한국어로 옮긴 것.

- 새 대화에서 시작할 것(이전 대화 내용이 결과에 섞이지 않게).
- 무료 화면의 모델은 실제 서버에서 쓸 API 모델과 조금 다를 수 있음 — 말투를 살리는 성향을 보는 용도.
- 판정은 가능하면 결과가 어느 AI 것인지 가리고(A·B), 태국어·일본어·중국어를 아는 사람에게.

## 묶음 1 — 아티스트 메시지 → 팬 언어 (팬 화면 "번역 보기")

```
너는 유료 메시지 앱 "토피"의 번역기야. 아티스트가 구독한 팬에게 개인 메시지를 보내고 팬이 답장하는 앱이야.
아래 아티스트 메시지 12개를 각각 태국어, 일본어, 중국어(번체, 대만식)로 번역해 줘. 언어별로 묶어서 번호를 붙여 줘.
- 원래 말투와 다정함을 살릴 것. 반말·애교 섞인 친근한 말투는 그대로 친근하게, 존댓말이면 다정한 존댓말로. 딱딱하게 바꾸지 말 것.
- 이모티콘, 줄바꿈, 이름, {{name}}은 그대로 둘 것({{name}}은 나중에 팬 닉네임으로 바뀌는 자리).
- 번역문만 출력하고 설명·발음 표기는 붙이지 말 것.

1. {{name}}야 오늘 촬영 끝났어! 너무 피곤한데 너 생각나서 연락했어 ㅎㅎ
2. 오늘 비 온대~ 우산 꼭 챙겨 🌂 감기 걸리면 나한테 혼나
3. 밥은 먹었쪄? 나는 방금 김밥 먹었는데 너랑 같이 먹고 싶당 🥺
4. 헐 대박 ㅋㅋㅋㅋㅋ 너 진짜 웃기다
5. 오늘 무대 어땠어?? 떨려서 죽는 줄 ㅠㅠ
6. 잘 자 {{name}} 꿈에서 만나 💜
7. 아 진짜 보고 싶다… 언제 와?
8. 여러분 오늘도 고생 많으셨어요 :) 따뜻하게 입고 다니세요!
9. 짠! 🎉
10. 오늘 하루 어땠어?
    나는 대본 리딩하고
    운동하고
    지금 집 가는 길 🚗
11. 비밀인데… 다음 주에 좋은 소식 있을지도? 🤫
12. 너네 없으면 나 어떡해 진짜로 💕💕
```

## 묶음 2 — 팬 답장 → 한국어 (아티스트 화면 "번역 보기")

```
너는 유료 메시지 앱 "토피"의 번역기야. 팬이 아티스트에게 보낸 답장을 한국어로 번역해 줘.
- 팬의 편하고 다정한 말투를 살릴 것. 딱딱하게 바꾸지 말 것.
- 이모티콘, 줄바꿈, 이름은 그대로 둘 것. 웃음 표현은 한국어 느낌으로(예: ㅋㅋ).
- 번역문만 번호를 붙여 출력하고 설명은 붙이지 말 것.

1. พี่คะ วันนี้เหนื่อยไหมคะ 🥺 พักผ่อนเยอะๆ นะคะ
2. รักพี่ที่สุดในโลกเลย 💛💛
3. ฮือออ คิดถึงมากกก
4. 555555 ตลกมากกก
5. ละครตอนล่าสุดดีมากเลย ร้องไห้หนักมาก 😭
6. 今日もお疲れさま！ドラマ最高すぎて泣いた😭
7. おやすみなさい〜また明日ね💤
8. 哥哥今天辛苦了！好想你喔🥺
9. 哈哈哈哈哈笑死我了
10. 下次什麼時候來台灣？我們都在等你 💜
```

## 볼 것 (A·B 각각 ○/△/×)

| 기준 | 설명 |
|---|---|
| 말투 | 반말·애교가 친근하게 남았는지, 8번(존댓말)은 다정한 존댓말인지 |
| 이모티콘·줄바꿈 | 빠지거나 바뀌지 않았는지(10번 줄바꿈) |
| `{{name}}` | 1·6번에서 그대로인지(번역되거나 지워지면 안 됨) |
| 한국어 표현 | ㅋㅋ·ㅠㅠ·애교체(먹었쪄)를 자연스러운 그 나라 표현으로 바꿨는지 |
| 웃음 | 태국어 555, 중국어 哈哈를 한국어 ㅋㅋ 느낌으로 옮겼는지 |
| 군더더기 | 설명·발음 표기·따옴표 없이 번역만 나왔는지 |
| 원어민 느낌 | "아티스트가 진짜 보낸 것 같은" 쪽은 어디인지 |

결과(캡처나 고른 쪽)를 Claude에게 주면 그 AI로 서버 연결·모델 등급을 정한다.
